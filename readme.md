# TikTok Downloader Bot

Telegram bot untuk download video TikTok tanpa watermark.

## Features
- 📹 Download video TikTok tanpa watermark
- 🖼️ Download image slideshow dari TikTok
- 📊 Monitoring dashboard
- ☁️ Deploy ready (Render + Netlify)

## Setup
1. Clone repository
2. `npm install`
3. Copy `.env.example` to `.env`
4. Isi `BOT_TOKEN` dengan token bot Telegram
5. `npm start`

## Deployment
- Backend: Deploy ke Render
- Frontend: Deploy folder `web-dashboard-simple` ke Netlify
